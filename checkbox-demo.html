✨ Características del Nuevo Diseño

❌ Diseño Anterior

  • 20px de tamaño
  • Bordes simples grises
  • Color azul por defecto
  • Animaciones básicas
  • Sin efectos visuales

✅ Nuevo Diseño

  • 22px de tamaño (mejor visibilidad)
  • Bordes redondeados modernos
  • Gradiente usando color primario
  • Transiciones suaves (0.3s cubic-bezier)
  • Shadow effects al seleccionar
  • Ícono checkmark SVG personalizado
  • Efecto hover interactivo
  • Ring focus para accesibilidad
    • /* Estilos aplicados en: resources/css/components/forms.css */ .form-check-input { width: 22px; height: 22px; border: 2.5px solid #d0d0d0; border-radius: 6px; cursor: pointer; transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1); background-color: #ffffff; appearance: none; } .form-check-input:checked { background: linear-gradient(135deg, #8b1538 0%, #a0153a 100%); background-image: url("data:image/svg+xml,...checkmark SVG..."); box-shadow: 0 2px 8px rgba(139, 21, 56, 0.25); }
